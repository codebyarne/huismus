{% translate "Bouw mee aan Huismus" %}

{% translate "Huismus is open source. Code, vertalingen, testen en goede ideeën zijn welkom. Je hoeft geen boekhouder te zijn: de regels voor geld en facturen staan in de code en in de tests." %}

{% translate "Naar de code op GitHub" %} {% translate "Bekijk de issues" %}

{% translate "Waarmee het gemaakt is" %}

  • {% blocktranslate %}Django en SQLite: één proces en één databasebestand. Een back-up is een kopie van een map.{% endblocktranslate %}
  • {% blocktranslate %}HTMX en gewone CSS: schermen komen van de server. Geen JS-framework en geen build-stap; elk formulier werkt ook zonder JavaScript.{% endblocktranslate %}
  • {% blocktranslate %}WeasyPrint voor de pdf's.{% endblocktranslate %}
  • {% blocktranslate %}pywebview en PyInstaller voor de app op Mac en Windows, Docker voor een server of Raspberry Pi.{% endblocktranslate %}
  • {% blocktranslate %}pytest en Playwright: de browsertests draaien in Chromium, WebKit en Firefox.{% endblocktranslate %}

{% translate "Waar je mee kunt helpen" %}

  • {% blocktranslate %}Testen op Windows: Huismus wordt op een Mac gemaakt. Elke melding van iets wat op Windows raar doet, helpt.{% endblocktranslate %}
  • {% blocktranslate %}Vertalingen: Nederlands is de brontaal. Loop de Engelse teksten na, of voeg een taal toe.{% endblocktranslate %}
  • {% blocktranslate %}Bugs en wensen: open een issue. Kom je van Moneybird en gaat er iets mis bij het importeren, beschrijf het dan zonder echte gegevens.{% endblocktranslate %}
  • {% blocktranslate %}Code: kies een issue, of begin bij iets kleins. Voor iets groters bespreek je eerst de aanpak in een issue.{% endblocktranslate %}

{% translate "Zo begin je" %}

{% blocktranslate %}Je hebt Python 3.12 of nieuwer nodig, uv en Pango voor de pdf's (op een Mac: brew install pango).{% endblocktranslate %}

git clone {{ repository }}.git
cd huismus
uv sync
./scripts/demo-server.sh     # {% translate "Huismus met negen jaar nepdata" %}
./scripts/verify.sh          # {% translate "alle checks in één commando" %}

{% blocktranslate %}./scripts/verify.sh is de poort: een wijziging is klaar als die groen is. Hoe de code in elkaar zit, staat in docs/architectuur.md, het ontwerp in SPEC.md.{% endblocktranslate %}

{% translate "De regels van het huis" %}

{% translate "Een paar regels zijn hard, omdat het om iemands administratie gaat. De tests en de database bewaken ze." %}

  • {% blocktranslate %}Geld in centen: bedragen zijn hele getallen, nooit een float.{% endblocktranslate %}
  • {% blocktranslate %}Uitgegeven is vast: een uitgegeven factuur verandert niet meer. Corrigeren doe je met een creditnota.{% endblocktranslate %}
  • {% blocktranslate %}Nummers zonder gaten: een nummer krijgt een factuur pas bij het uitgeven.{% endblocktranslate %}
  • {% blocktranslate %}Eén functie voor totalen: het scherm, de pdf en de import rekenen op dezelfde manier.{% endblocktranslate %}
  • {% blocktranslate %}Geen echte gegevens: nooit een echte factuur, IBAN of export in de repo, een test of een issue.{% endblocktranslate %}
