# Op je telefoon

Draait Huismus op een server, zoals een Raspberry Pi of een NAS? Dan zet je
hem als app op je telefoon, tablet of laptop. Je hebt er geen app store voor
nodig. Je krijgt een eigen icoon en een venster zonder adresbalk.

## Huismus als app installeren

Open Huismus in de browser en kies:

- **iPhone en iPad:** Safari → Deel → **Zet op beginscherm**.
- **Android:** Chrome → menu → **App installeren**.
- **Chrome of Edge op een computer:** het installeer-icoon in de adresbalk,
  of menu → **App installeren**.
- **Mac:** Safari → Archief → **Voeg toe aan Dock**.

Dit werkt alleen als het adres van Huismus met `https://` begint, of als je
hem opent op de computer waar hij draait (via `localhost`). Zie je de knop
niet? Kijk dan eerst naar het begin van het adres.

## Een pdf delen

De knop **PDF** bij een factuur, creditnota of offerte opent een pagina met
de pdf. Bovenaan staat een knop terug naar het document. In de app op je
beginscherm staat daar **Delen**: zo mail je de pdf of bewaar je hem in
Bestanden. In de browser staat er **Downloaden**, en als de browser kan
delen ook **Delen**.

## Wat er op je telefoon staat

Niets van je administratie. Alles blijft op de server, en de app laat alleen
zien wat de server stuurt. Kan de app de server niet bereiken, bijvoorbeeld
omdat je geen wifi hebt, je VPN uit staat of de server uit is? Dan zegt een
pagina van Huismus dat, in plaats van een foutmelding van de browser.
